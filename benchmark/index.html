Benchmark Scenarios Explanation

Simple: A grid with no walls. It mainly shows the basic pathfinding overhead.

Exhaustive: End node is completely surrounded by walls which stresses the ability of the pathfinding library to scan through all nodes. There is significant memory usage in this scenario.

Complex (Arc): A semi-circular wall (radius ~size/3) surrounds the end node. This forces the pathfinding library to navigate around the "fortress" barrier to reach the goal, stressing the heuristic and testing if an optimal path can be found.
